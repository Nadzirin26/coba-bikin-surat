# Kartu ulang tahun

Versi terbaru untuk Nabila berada di [`nabila-birthday`](nabila-birthday/README.md), dengan kartu interaktif, penguncian waktu mulai 10 Oktober 2026 pukul 00.00 WIB, serta editor privat.

Website: https://nabila-birthday-mauve.vercel.app

Untuk menjalankan lokal:

```powershell
cd nabila-birthday
# Salin .env.example ke .env.local dan isi secret privat.
npm run dev
```

Jika menghubungkan repo ini ke Vercel, gunakan **Root Directory: `nabila-birthday`**. Editor online memerlukan penyimpanan Upstash Redis; persetujuan ketentuan Upstash dan koneksi penyimpanan masih perlu diselesaikan. Secret tidak disertakan di repo.

Berkas kartu versi lama di root dipertahankan.
